1 · Set up

Terminal 1, start the mock CRM:

cd D:\CallTracker\mock-server; npm start

Terminal 2, reinstall the app on the phone (PowerShell):

$adb="$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb uninstall com.example.calltracker
& $adb reverse tcp:3000 tcp:3000
& $adb install D:\CallTracker\dist\CallTracker-1.0-device.apk
  • Uninstall wipes the app's local database, number answers and settings.
  • Run adb reverse again whenever you reconnect the USB cable.
  • Open the app once and allow all permissions. Android sends no call events to an app that was never opened.
  • Watch the CRM by opening http://localhost:3000/__admin/state in a browser and refreshing after each step.

Testing "found in CRM"

The 5 sample records use made-up numbers, so real calls never match them. To test linking to an existing contact, add your friend's number (E.164, e.g. +9198…) to mock-server/src/seed.js, then reset the CRM while the server runs:

curl.exe -X POST http://localhost:3000/__admin/reset

Then mark that friend's call Professional: the call links to the existing contact and no new lead is created.
